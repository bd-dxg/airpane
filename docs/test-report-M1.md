## 3. 验收与试用反馈中发现并修复的问题

### 3.1 第一轮验收（D-030 ~ D-035）

| 问题 | 现象 | 修复 |
| --- | --- | --- |
| 坐标系混用 | 窗口每移动一次就膨胀 80–100px（微信 1053×992 → 1147×1079） | 统一使用 `DWMWA_EXTENDED_FRAME_BOUNDS`，`move_window` 内部只补偿一次（D-030） |

## 5. 与 M0 的差异

- M0 只做到「枚举 + 事件 + 预览区 + 点击切换 + 动画验证」；M1 引入了真实窗口搬动、状态落盘与崩溃恢复。
- M0 的验收全部是诊断示例；M1 有了可持续运行的主程序（预览区 + 舞台区 + 快捷键 + 工具区）。
- M0 的 `GetWindowRect` 语义在 M1 被替换为 DWM 可见边界（D-030），旧的 `rect` 消费方（缩略图宽高比）随之更准确。
- 事件同步从「事件 + 1Hz 全量校准」调整为「事件 + 1Hz 已跟踪校准 + 每 10 秒全量兜底」（D-035）；进出全屏额外走 `EVENT_OBJECT_LOCATIONCHANGE`（D-057）。
- 预览区从「只列非活跃窗口、MRU 顺序、纯缩略图」变成「全部窗口 + 固定/手动顺序 + 大图标条 + 主题跟随」。
