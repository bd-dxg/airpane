## 3. 已知缺口与风险

1. **Win10 兼容性完全未验证**，包括 Mica 降级、DWM 行为差异。M4 必须补齐，否则不能在下载页宣称支持 Win10 22H2。
2. **DPI 相关代码没有在非 100% 缩放下跑过**。`GetDpiForWindow` 换算逻辑简单，但 `WM_DPICHANGED` 后的重排只在代码层面覆盖。
3. **事件同步依赖 1Hz 校准**（D-020）。两次校准之间（最多 1 秒）可能出现列表与实际不一致；M1 需要把校准频率与场景（例如进入 Stage 模式时立即校准一次）重新评估。
4. **DWM 缩略图对 UWP 窗口的表现**未单独验证（T0.4b 只用了 Win32 窗口）。
5. **前台切换在 UAC 安全桌面、系统弹窗场景下**未验证（T0.5）。

## 4. 环境限制导致的调整

- 原计划的「Win10 22H2 + Win11 双系统跑通」改为 Win11 单系统跑通（D-003）。
- 动画性能结论来自核显，对独显用户偏保守；高刷新率显示器未测。
